# Restored test outputs

The actual restored images this model produced on the released test set
(`Test_NoisyLR/NoisyLR`, 400 arrays), generated by:

```bash
python inference.py --input_dir <Test_NoisyLR/NoisyLR> --output_dir restored_test_outputs
```

- 400 files, one per input, **identical filenames** (`000000.npy` … `000399.npy`)
- `.npy`, `float32`, shape `(256, 256)` — ×2 of each `(128, 128)` input
- every value clipped to `[0, 1]`
- produced by `weights/best.pt` (step 4000, EMA, seed 1337) with the default
  single-pass path, deterministic

These are the model's real outputs, not samples or illustrations. The test set has
no ground truth, so no metrics are computed from it — all reported metrics come from
the held-out split of `train/`.
