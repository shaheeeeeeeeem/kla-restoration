# Installable, cross-platform requirements. Versions are the exact ones from the
# training environment (see requirements-freeze-windows.txt for the literal
# `pip freeze`), with two deliberate differences so this file installs cleanly on a
# Linux evaluation machine:
#
#   1. Windows-only packages are excluded (the freeze contains pywinpty==3.0.3,
#      which has no Linux wheel and hard-fails `pip install -r`).
#   2. The `+cu126` local version suffixes are dropped from torch/torchvision.
#      `torch==2.12.0+cu126` does not resolve from plain PyPI; `torch==2.12.0` does,
#      and pip selects the right CUDA build for the platform.
#
# For the exact CUDA 12.6 builds we trained and benchmarked on:
#   pip install torch==2.12.0 torchvision==0.27.0 --index-url https://download.pytorch.org/whl/cu126
